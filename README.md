# Isharati - Sign Language Learning Application

## Overview

Isharati is a mobile application designed to help deaf and hard-of-hearing individuals learn sign language through an organized and user-friendly educational experience. The application provides categorized sign language content, making it easier for users to discover, learn, and understand different signs used in everyday communication.

## Features

### Sign Categories

The application organizes signs into multiple categories such as:

* Food
* Fruits
* Animals
* Transportation
* And many other categories

Each category contains a collection of related signs. For example, the Fruits category includes signs such as Apple, Orange, Banana, and more.

### Sign Details

When a user selects a sign, the application displays:

* An image demonstrating the sign.
* The corresponding word or meaning.
* Additional information or a description to help users better understand the sign and its usage.

### Admin Dashboard

The system includes an administrative dashboard that allows administrators to:

* Add new categories.
* Add new signs and assign them to categories.
* Edit existing data.
* Delete categories and signs when necessary.

## Technologies Used

* Flutter for cross-platform mobile development.
* Provider for state management.
* Supabase as the backend service.
* Supabase Database for data storage.
* Supabase Storage for managing sign images.

## Project Goal

The main goal of Isharati is to support sign language education by providing an accessible digital platform that helps users learn, explore, and understand sign language in a simple and effective way. The application aims to improve communication and contribute to the social inclusion of deaf and hard-of-hearing individuals.
